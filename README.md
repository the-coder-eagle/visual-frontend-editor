# 画页 · 前端可视化编辑器

导入单个 HTML，直接在页面上修改，预览交互，再导出 HTML。文件始终在浏览器本地处理。

## 打开

[在线体验](https://eaglecoder.cn/#editor) · [作者](https://github.com/the-coder-eagle)

本地运行：`python -m http.server 8787 --bind 127.0.0.1`，打开 http://127.0.0.1:8787/ 。无需安装 npm 依赖，运行库已包含在 `vendor/`。线上版本随部署更新。

## 编辑流程

1. **导入**：选择 HTML 文件或粘贴代码。默认勾选「保留页面交互」，保留内嵌脚本供预览和导出。
2. **点选修改**：双击文字直接输入；选中后点击「编辑元素」，按对象提供改文字、改链接、换图片和高级编辑。右键打开同一份菜单。
3. **样式**：打开右侧面板，调整字体、颜色、尺寸、间距和排列。常用／更多样式切换保留；容器支持横排、竖排、分列和自定义 CSS。
4. **预览**：运行页面的内嵌 JavaScript，体验翻页、按钮、表单和进度交互。沿用当前桌面／手机宽度，点击「返回编辑」继续修改。
5. **导出**：直接下载 `edited-page.html`。

右上角 `•••` 收纳「页面代码」「版本」「图层」「添加元素」和帮助。HTML 编辑包含页面、样式和保留的脚本，应用前自动保存「修改 HTML 前」版本；取消不改变页面。整页应用后可从版本恢复，普通元素修改使用撤销／重做。

导入有隐藏章节的页面时，工具栏显示章节选择。选择章节后可以编辑其中的文字和样式，临时显示状态不会写入导出。由脚本运行后生成的节点在预览中显示，修改这类节点需要编辑 HTML 中的脚本。

链接支持修改指向、打开目标、取消链接。网页链接在新标签页打开；`#目标` 定位并显示隐藏目标。相对路径原样导出。

## 元素高级编辑

选中元素后打开「编辑元素 → 高级编辑」，也可右键进入。窗口集中显示元素 HTML、全部属性、元素与祖先的匹配 CSS、当前计算样式，以及内嵌脚本；脚本按 ID、类名和业务属性的文本引用排序，显示引用行。它提供源码线索，不执行脚本分析运行时依赖。「在 HTML 中编辑」和「编辑此脚本」会定位到整页代码中的对应内容，应用前仍自动保存版本。

已有 `button[data-page]` 或 `a[data-page]` 数字章节入口的页面，可以在「点击后前往」中直接选择章节。预览和导出会复用原章节按钮的点击行为；原脚本保持原样。选择「原有行为」可移除覆盖。修改支持撤销、重做、工程恢复和导出再次导入；取消保留页面交互时也会清理该行为。

本地已在学习工作台上手动验证「继续学习 → 03 Git 与 Linux」，预览成功进入第 3 章。

## 保存与布局

启动时选择「试用样例」进入默认海报，或选择「继续上次」恢复本地工程。试用样例或导入新页面前，上次工程会另存到「版本 → 上次工程」。修改自动保存到当前浏览器、当前站点的 IndexedDB；命名版本保留最近 8 份。更换端口或浏览器不会同步工程。

自由移动保留原布局占位；尺寸手柄和方向键可微调，Shift + 方向键移动 10px。结构排序在「样式 → 更多样式」内。桌面和手机共用样式，移动后应检查两种宽度。

PNG、JPEG、WebP 图片经签名检查和解码后以 Data URL 写入 HTML，单张最多 5 MB。图层支持重命名、锁定、复制及复制覆盖样式。

## HTML 范围与隔离

- 支持单页 HTML、内嵌 CSS 和内嵌 JavaScript。保留业务 ID、`name` 和普通 `data-*`，清理事件属性、外链脚本、外链样式、嵌入页面和 `data-gjs-*` 配置属性。
- 编辑画布使用禁止脚本的 sandbox 和 CSP。DOMPurify 保留 `reset` 等脚本依赖的标识；清理结果只进入隔离画布，不插入主站 DOM。
- 交互预览使用独立 `preview.html` 和仅含 `allow-scripts` 的 sandbox，无同源、弹窗、下载或顶层导航权限。CSP 阻断外部资源和 fetch 等请求。localStorage / sessionStorage 使用本次预览的临时数据，返回编辑后清空；导出的页面使用浏览器正常存储。
- iframe sandbox 不能阻止脚本导航自身框架，因此当前预览不是完全断网的执行环境。该限制同样适用于线上预览。主站读取和顶层跳转仍受 sandbox 限制。
- 编辑画布中的外部图片仍可请求其网址。关联本地文件不自动打包。依赖事件属性、外链资源或后端接口的页面需要调整；React/Vue 工程、ZIP 和多页面项目不在当前导入范围。
- GrapesJS 重新解析并导出 HTML/CSS，可能改变结构、选择器和格式。修改脚本依赖的元素后应在预览中验证交互。

## 实现

`app.js` 连接编辑引擎与面板；`tools.js` 管理保存、版本、图片和图层；`document.js` 管理脚本保留和章节显示；`links.js` 管理就地操作；`inspect.js` 管理元素详情、脚本引用定位和章节选择；`preview.html` / `preview.js` 提供隔离交互预览。

依赖固定为 [GrapesJS](https://github.com/GrapesJS/grapesjs) 0.23.9 和 [DOMPurify](https://github.com/cure53/DOMPurify) 3.4.17。没有上传接口或服务器存储，遥测关闭。
